# Finances Tracker

Store all of your financial information in one place, locally. Your data is saved to a local `private/info.json` file and never leaves your machine.

## Setup

1. Install dependencies:

   ```
   npm install
   ```

2. Run the setup script. This creates the `private/info.json` file used to store your information:

   ```
   npm run setup
   ```

3. Start the app:

   ```
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
